# Mobile-App-Djezzy
##  Architecture Technique
* **Frontend Mobile :** Flutter / Dart (Rendu natif 60 FPS pour la cartographie)
* **Backend API :** Node.js / Express.js
* **Base de données Opérationnelle :** Neon (Serverless PostgreSQL)
* ##  Fonctionnalités Principales
. **Algorithme de Load Balancing :** Assignation déterministe des pannes réseau aux techniciens selon leur charge de travail en temps réel.
